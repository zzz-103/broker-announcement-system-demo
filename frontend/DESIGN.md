# DESIGN.md

## 气质与意象
- **核心定位**：金融数据产品，面向证券公司管理层和信息技术负责人
- **气质关键词**：专业、克制、高信息密度、金融终端感
- **参考标杆**：Wind金融终端的专业性 + 现代SaaS数据产品的清晰度

## 配色方案
- **深蓝导航**：`#162B49` — 沉稳的金融蓝
- **科技蓝**：`#2563EB` — 交互高亮色
- **青绿色**：`#0F9F8F` — 金额强调色
- **提示橙**：`#F59E0B` — 警示与提示
- **风险红**：`#D64545` — 错误与风险
- **页面背景**：`#F5F7FA` — 极浅灰白
- **卡片背景**：`#FFFFFF` — 纯白
- **主文字**：`#172033` — 深色正文
- **次级文字**：`#667085` — 辅助信息
- **边框**：`#E4E9F0` — 极轻分隔线

## 字体排版
- **字体族**：PingFang SC, Microsoft YaHei, 系统无衬线字体
- **字号层级**：主标题22px → 模块标题16px → 正文13-14px → 指标数字28-32px → 辅助说明11-12px
- **数字排版**：金额使用 `tabular-nums` 等宽数字

## 动效与交互
- **运动性格**：极度克制，仅 hover 过渡
- **卡片 hover**：边框微变 + 极轻阴影，150ms 过渡
- **表格行 hover**：`hover:bg-[#F8FAFC]` 微妙底色变化

## 设计禁忌
- 禁止大面积渐变
- 禁止霓虹发光
- 禁止过重阴影
- 禁止大面积空白
- 禁止夸张大数字
- 禁止卡通图标
- 禁止五颜六色标签
- 禁止普通后台管理模板感
